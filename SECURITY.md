# Security policy

This is a development scaffold. There is no supported drive release yet.

Security issues include malicious or substituted downloads, unsafe executable
placement, manifest failures, unintended network access and dangerous errors in
emergency instructions. A valid checksum alone does not establish that an input
is safe or licensed for redistribution.

## Report privately

[[VERIFY: configure GitHub private vulnerability reporting or name a private
security contact before public launch]]. No confidential reporting channel has
been confirmed for this scaffold. Do not publish exploit details, personal data
or secrets in public issues while that route is being established.

A private report should identify the affected commit or release, describe the
problem and provide a minimal reproduction if available. Do not include private
information about real households or sensitive infrastructure.

Maintainers must confirm download provenance, checksums, APK signers and license
proofs before cargo is placed. Release validation and human content review remain
required even when automated checks pass. No response-time commitment is made
until maintainers establish a reporting process.
