# Code of conduct

Treat contributors, reviewers and future users with respect. Make room for
different languages, abilities, experience and points of view. Critique the work
with evidence and explain corrections in plain language.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation and
publishing someone's private information are not acceptable. These rules apply
in project discussions, reviews and other project spaces.

Maintainers may edit or remove harmful contributions and restrict participation.
They should explain decisions when doing so does not expose private information.
Maintainers involved in a report should step aside from deciding that report.

The confidential reporting route must be established before public launch:
[[VERIFY: maintainer-designated private conduct reporting contact]]. Do not post
private details or allegations about another person in a public issue.
