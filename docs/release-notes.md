Common Knowledge provides offline emergency reference documents in fifteen language editions.
The development images contain the project's core PDFs and static laptop pages.
Full images carry additional maps, reference libraries, optional applications and a local LLM;
their hashes and download locations are published separately on the verification site.

Check SHA256SUMS before copying an image. The manifest inside each image covers
every other file; its own checksum is supplied separately. Catalog provenance and
corresponding GPL application source archives accompany the release.

Spanish and the thirteen quick-start editions are unreviewed machine translations.
The local LLM is experimental and can be wrong. Follow the printed card if they disagree.
